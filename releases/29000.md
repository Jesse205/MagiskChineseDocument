# 2025.5.14 Magisk v29.0

这个版本表面上看起来变化不大，但整个代码库经历了大规模重构和迁移。Magisk 的原生代码以前主要是 C++，但自 2022 年 4 月以来，多位贡献者和作者一直在逐步用 Rust 重写部分代码。经过多年努力，项目的 Rust 化逐渐加速；截至此版本发布时，超过 40% 的原生代码已用 Rust 重写，还有若干主要子系统的重写已在 PR 队列中，计划在下一个版本合并。

引入新语言的原因并不是为了减少内存安全问题（虽然这是附带好处），而是为了用更现代的编程语言开发 Magisk。

- [General] 大规模内部重构和代码迁移
- [App] 支持下载使用 XZ 压缩的模块 zip 文件
- [App] 当系统动画被禁用时禁用应用动画
- [MagiskMount] 支持使用空白文件节点，通过模块以 systemless 方式删除文件
- [MagiskInit] 重新设计 sepolicy 修补和注入逻辑
- [MagiskSU] 更好的 TTY/PTY 支持
